# Task 1.2 SW101が解答に出てこない理由 / SW110で既に設定済みに見える理由

## 質問

CCIE_train_hub/Questions/pattern2/pattern2_q2.mdの問題文と回答について

・SW101において回答で設定されていないのはすでに問題文の設定が事前に行われているから？もしそうだとしたらどうやって確認される？
・SW111でsh etherchannelとsh vlanを見ていたら問題文の設定がすでに設定されていると思ったんだけどこれに関してはどう？

## 回答

### SW101が回答に出てこない理由

SW101の初期コンフィグ（`EI_v2.yaml`）では、`vlan 2000-2001`が既に作成済み、Po1/Po3ともトランクモードで`switchport trunk allowed vlan`の制限がない（＝デフォルトで全VLANタグ付き許可）。

- **Po3**（Gi2/0-1）は初期状態で`channel-group 3 mode active`が既に設定済み＝メンバーポートとして既にバンドルされている。ここは本当に追加設定不要。
- **Po1**（Gi1/2-3）は初期状態でchannel-group未設定＝物理的にまだPo1のメンバーになっていない。これはTask 1.3（EtherChannel/STP）で解決される。実際、Task 1.3のSW101解答に`channel-group 1 mode active`と`switchport trunk allowed vlan 1,2000,2001`が含まれている。

つまりPo1のメンバー追加（EtherChannel構築）という別タスクの作業のついでに、VLANタグ付けの要件も一緒に満たしている構成。Task 1.2の解答だけを見るとSW101が空白に見えるが、実質的にはTask 1.3の中で満たされている。

確認方法:
```
show vlan brief                 # VLAN 2000/2001が既に存在するか
show interfaces trunk           # Po1/Po3がトランクとして動作し、VLAN2000/2001が許可・アクティブか
show etherchannel summary       # メンバーポートとバンドル状態（Task1.3前はPo1がメンバーなしのはず）
```

### SW110（「SW111」は打ち間違いと思われる）で既に設定済みに見えた件

観察は正しい。SW110の初期コンフィグでは、Po1（Gi1/0-1, `channel-group 1 mode on`）とPo2（Gi1/2-3, `channel-group 2 mode passive`）のどちらも初期状態で既にメンバーポート割り当て済み、かつVLAN許可制限がないため全VLANタグ付きで通っている。

だからこそPattern 2のTask 1.2解答でSW110に書かれているのは以下の2行（Gi0/0・Gi0/1のアクセスポート設定）だけ:
```
interface GigabitEthernet0/0
switchport
switchport mode access
switchport access vlan 2000

interface GigabitEthernet0/1
switchport
switchport mode access
switchport access vlan 2001
```
表の要件のうち「Po1・Po2（タグあり）」は初期コンフィグだけで既に満たされており、追加設定が必要なのはGi0/0・Gi0/1（タグなし＝アクセスポート、初期コンフィグに未登場）のみ。

### 補足

SW102の初期コンフィグも確認したところ、Po2（Gi1/2-3, `channel-group 2 mode passive`）とPo3（Gi2/0-1, `channel-group 3 mode active`）は既にメンバー割り当て済み。ただしSW110側のGi1/2-3も`channel-group 2 mode passive`になっており、passive-passive同士はLACPでバンドルが成立しない（最低片側はactiveが必要）。これはTask 1.3側でSW102の`channel-group 2 mode passive`→`mode active`に修正されている。VLANの話とは別に、初期状態のままではEtherChannelが正しく機能しないという別の罠が仕込まれている点は注意。
