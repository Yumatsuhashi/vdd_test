# Task 1.2 SW601をwipeして初期コンフィグ確認したらtrunkが既に入っていた件

## 質問

```
SW601>en
SW601#sh int trun

Port        Mode             Encapsulation  Status        Native vlan
Gi2/0       on               802.1q         trunking      1

Port        Vlans allowed on trunk
Gi2/0       1-4094

Port        Vlans allowed and active in management domain
Gi2/0       1,2000-2001

Port        Vlans in spanning tree forwarding state and not pruned
Gi2/0       1,2000-2001
```
wipeして初期コンフィグにしてから確認しているがすでに設定が入っている
CCIE_train_hub/EI_v2.yamlこれに事前設定が入っているのか？

## 回答

はい、`EI_v2.yaml`に事前設定が入っている。SW601の初期コンフィグ:

```yaml
interface GigabitEthernet2/0
 switchport trunk encapsulation dot1q
 switchport mode trunk
```

これがwipe後の出力と完全に一致する。

| 出力項目 | 値 | 初期コンフィグとの対応 |
|---|---|---|
| Mode / Encapsulation / Status | on / 802.1q / trunking | `switchport trunk encapsulation dot1q` + `switchport mode trunk` |
| Vlans allowed on trunk | 1-4094 | `switchport trunk allowed vlan` の指定がないためデフォルトの全VLAN許可のまま |
| Vlans allowed and active in management domain | 1,2000-2001 | 実際にVLANデータベースに存在するのがVLAN1と`vlan 2000-2001`（初期コンフィグで作成済み）だけだから |
| STP forwarding | 1,2000-2001 | 特にSTPでブロックされているVLANがない |

SW601は初めから「Gi2/0がdot1qトランクとして立ち上がっている」状態でラボが渡される。ただしVLAN許可の絞り込み（`switchport trunk allowed vlan 1,2000,2001`）はまだ入っていない（`1-4094`のまま＝未制限）ので、そこはTask 1.2の解答コマンドで追加する必要がある。

### 前回のSW602の件とのつながり

これは前回確認したSW602の件（[Task 1.2 SW602で既に絞られたトランクは適用済みの証拠](2026-07-31_q2_SW602で既に絞られたトランクは適用済みの証拠.md)）を裏付ける結果。SW602の初期コンフィグもSW601と全く同じ形（`switchport trunk encapsulation dot1q` + `switchport mode trunk`のみ、VLAN制限なし）なので、本来wipe直後なら「Vlans allowed on trunk」は`1-4094`と表示されるはず。前回のSW602の出力は`1,2000-2001`に絞られていたので、「まだwipeしていない（既に`switchport trunk allowed vlan 1,2000,2001`が投入済みの）状態だった」という結論が、今回のSW601の正しいwipe後の挙動と比較することで裏付けられた。

まとめ:
- トランクモード自体（`mode trunk` + `encapsulation dot1q`）は初期コンフィグ済み
- VLAN許可の絞り込み（`allowed vlan 1,2000,2001`）だけがTask 1.2で追加すべき差分
