# Task 1.2 SW602の show interfaces trunk が既に絞られている＝設定済みの証拠

## 質問

```
SW602#sh int trun

Port        Mode             Encapsulation  Status        Native vlan
Gi2/0       on               802.1q         trunking      1

Port        Vlans allowed on trunk
Gi2/0       1,2000-2001

Port        Vlans allowed and active in management domain
Gi2/0       1,2000-2001

Port        Vlans in spanning tree forwarding state and not pruned
Gi2/0       1,20
```

SW602においてすでにこうなっているんだけどこれは追加の設定をしなくても題意を満たしている？

もし満たしていたらなぜ回答で以下を入れている？

```
interface GigabitEthernet2/0
switchport
switchport trunk encapsulation dot1q
switchport mode trunk
switchport trunk allowed vlan 1,2000,2001
```

## 回答

結論: その状態は「何もしなくても満たされている初期状態」ではない。むしろ逆で、その出力は既に回答の設定コマンドが適用された後の状態。

### 根拠

SW602の初期コンフィグ（`EI_v2.yaml`）:

```
interface GigabitEthernet2/0
 switchport trunk encapsulation dot1q
 switchport mode trunk
```

`switchport trunk allowed vlan` の指定が一切ない。この場合IOSのデフォルト動作は「全VLAN（1〜4094）をタグ付きで許可」。

`show interfaces trunk`の出力には4セクションあり意味が異なる:

| セクション | 意味 |
|---|---|
| Vlans allowed on trunk | 静的に設定された許可VLANリスト（制限コマンドがなければ常に`1-4094`と表示される） |
| Vlans allowed and active in management domain | 上記のうち実在VLANだけに絞ったもの |
| Vlans in spanning tree forwarding state... | さらにSTP forwarding状態のものだけに絞ったもの |

初期状態のままなら1番目の「Vlans allowed on trunk」は`1-4094`と表示されるはず。しかし質問の出力は`1,2000-2001`となっており、**1番目の時点で既に絞られている**。これは`switchport trunk allowed vlan`の制限コマンドが既にconfigに入っていることの動かぬ証拠（制限がなければこの1番目のセクションは絶対に`1-4094`のまま）。

つまり観測しているSW602は既に回答の

```
interface GigabitEthernet2/0
switchport
switchport trunk encapsulation dot1q
switchport mode trunk
switchport trunk allowed vlan 1,2000,2001
```

が適用済みの状態。真っさらな初期状態を見たい場合は`show running-config interface Gi2/0`で`switchport trunk allowed vlan 1,2000,2001`の行が実際に走っているか確認するか、ノードをリロードしてから再度確認する。

### 補足: allow allのままでも機能的には要件を満たせるのに、なぜ回答は1,2000,2001に絞るのか

問題文の「802.1Qタグあり：対象VLANをタグ付きで転送するトランクポート」だけを読むと、デフォルトの全VLAN許可のままでもVLAN2000/2001はタグ付きで転送されるため機能的には要件を満たす。それでも回答が明示的に`1,2000,2001`へ絞っているのは、不要なVLANをトランクに流さないトランクプルーニングという一般的なベストプラクティスによるものと考えられる。SW101・SW102・SW601・SW602・SW610のどのトランクでも一貫して`1,2000,2001`に絞られており、Pattern2全体で意図的に統一された設計方針と見られる。
