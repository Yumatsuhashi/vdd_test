# Task 1.6 — SW610 に何も設定しない理由（Task 1.2 では設定対象である点も含む）

## 質問

またSW610で何も設定していないのはなぜ

## 回答

Task 1.6（EIGRP）で SW610 が対象外なのは、**SW610 がルーティングをしない純 L2 アクセススイッチだから**。
「触らない機器」なのではなく、「この設問ではやることが無い機器」。実際 Task 1.2（VLAN）では SW610 も設定対象になっている。

### 1. ルーテッドインターフェースが 1 本も無い

SW610 の初期コンフィグ全量（EI_v2.yaml 3971〜4004 行）:

```ios
hostname SW610
vtp mode transparent
spanning-tree mode pvst
vlan 2001
!
interface GigabitEthernet2/0          ← SW601 へのアップリンク
 switchport trunk allowed vlan 1,2000
 switchport trunk encapsulation dot1q
 switchport mode trunk
!
interface GigabitEthernet2/1          ← SW602 へのアップリンク
 switchport trunk allowed vlan 1,2000
 switchport trunk encapsulation dot1q
 switchport mode trunk
!
interface Vlan2000
 ip address 10.6.100.10 255.255.255.0
```

アップリンク 2 本はどちらも `switchport mode trunk`。SW601 / SW602 のように `no switchport` で /30 を振ったルーテッドポートが 1 本も無い。
EIGRP は「ルーテッドインターフェースを起点に隣接を張り、そのインターフェースが属するサブネットを広報する」プロトコルなので、
乗せる場所そのものが存在しない。

### 2. 唯一の L3（Vlan2000 SVI）は広報する価値のあるサブネットではない

`Vlan2000 = 10.6.100.10/24` は、SW601 / SW602 が `network 10.0.0.0` で**すでに広報済みの 10.6.100.0/24 上の 1 ホストアドレス**。
SW610 が EIGRP を喋っても、新しく広報できるプレフィックスは何も増えない（自分の管理 IP が既存サブネットに含まれているだけ）。

仮に SW610 で EIGRP を有効化すると、Vlan2000 セグメント上に SW601・SW602・SW610 の 3 者が並ぶことになり、
隣接が 2 本増えるだけで経路は 1 本も増えない。純粋なオーバーヘッド。

### 3. 問題文の要件がそもそも「ルートを伝播する機器」の話

> ブランチ3において、LANから Xander の WAN へルートを伝播できるように、IGP を設定しなさい

ルートを伝播する経路は `SW601/SW602（LAN ゲートウェイ）→ R61/R62 → SP（BGP）`。
SW610 はこの経路の途中に L3 として登場しない。PC61 / PC62 のフレームを Vlan2000 のまま SW601 / SW602 へ橋渡しするだけで、
デフォルトゲートウェイは SW601 / SW602 の HSRP VIP `10.6.100.1`（SW601 が priority 110 で Active）。
L3 の冗長性はアクセス層ではなくディストリビューション層（SW601/SW602 の HSRP）で担保する、という典型的な階層設計になっている。

### 4. ただし SW610 は「触らない機器」ではない — Task 1.2 では設定対象

同じ解答 HTML の Task 1.2（VLAN）では SW610 に 🔴 差分ありのマークが付いており、Pattern 2 の解答は以下:

```ios
interface GigabitEthernet0/0
 switchport mode access
 switchport access vlan 2000        ← PC61 収容
!
interface GigabitEthernet0/1
 switchport
 switchport mode access
 switchport access vlan 2001        ← PC62 収容
!
interface range GigabitEthernet2/0-1
 switchport
 switchport trunk encapsulation dot1q
 switchport mode trunk
 switchport trunk allowed vlan add 2001   ← 初期は 1,2000 のみ。2001 を追加
```

初期コンフィグで `vlan 2001` の宣言だけあってトランクの allowed vlan に 2001 が入っていないのは、Task 1.2 の作業対象として
意図的に穴を空けてあるため。つまり SW610 の役割は**L2 の VLAN 収容と転送に閉じている**ので、L2 のタスク（1.2）では登場し、
L3 のタスク（1.6）では登場しない、という切り分け。

### 判断のしかた（実機での確認手順）

Branch3 のどの機器に EIGRP が要るかは、次の 1 コマンドで機械的に切り分けられる:

```
show ip interface brief | exclude unassigned
```

- **ルーテッドポート（Gi0/x に IP がある）が出る** → R61 / R62 / SW601 / SW602 = EIGRP 対象
- **SVI が 1 個だけ、しかもそれが上位と同じサブネット** → SW610 = 対象外

または `show interfaces status` / `show interfaces trunk` で全アップリンクが trunk なら L2 専用機と判断できる。
