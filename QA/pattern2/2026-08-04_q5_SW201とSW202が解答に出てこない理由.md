# Pattern 2 Task 1.5 — SW201/SW202 に OSPF 設定がない理由（L3 かつ非 SD-WAN なのに解答に出てこない）

## 質問

q5でSW201,202に対してospfの設定をしていないのはなぜ？L3のインターフェースもあるし問題文に全てのすべての Layer 3 の非 SD-WAN ルータ間で設定しろと書いてあるじゃん

## 回答

**前提は完全に正しい。** SW201/SW202 は DC の Layer 3 非 SD-WAN スイッチであり、Task 1.5 の要件対象。
解答に出てこない理由は「対象外だから」ではなく、**初期コンフィグで既に全部設定済みで足すものが
1 つも無いから**。

### SW201 / SW202 の初期コンフィグ実測（EI_v2.yaml）

| SW201 | IP | 初期 OSPF | SW202 | IP | 初期 OSPF |
|---|---|---|---|---|---|
| Lo0 | 10.2.255.201/32 | ✅ area 0 | Lo0 | 10.2.255.202/32 | ✅ area 0 |
| Gi0/0 → R21 Gi4 | 10.2.10.2/30 | ✅ | Gi0/0 → R22 Gi4 | 10.2.11.2/30 | ✅ |
| Gi0/1 → R22 Gi3 | 10.2.12.2/30 | ✅ | Gi0/1 → R21 Gi3 | 10.2.13.2/30 | ✅ |
| Gi0/3 → SW202 | 10.2.109.1/30 | ✅ | Gi0/3 → SW201 | 10.2.109.2/30 | ✅ |
| Gi1/0 → SW212 | 10.2.23.1/30 | ✅ | Gi1/0 → SW211 | 10.2.22.1/30 | ✅ |
| Gi1/1 → SW211 | 10.2.20.1/30 | ✅ | Gi1/1 → SW212 | 10.2.21.1/30 | ✅ |
| Gi1/2 → SW101 | 10.2.241.1/30 | ✅ | Gi1/2 → SW102 | 10.2.242.1/30 | ✅ |
| Vlan3999 | 10.2.201.11/29 | ✅ | Vlan3999 | 10.2.202.11/29 | ✅ |
| Vlan4000 | 10.2.201.3/29 | ✅ | Vlan4000 | 10.2.202.3/29 | ✅ |
| **Gi0/2** | — | trunk（L2） | **Gi0/2** | — | trunk（L2） |
| **Gi1/3** | — | trunk（L2） | **Gi1/3** | — | trunk（L2） |

L3 インターフェースは 9 本すべて `ip ospf 1 area 0` 済み。**差分ゼロ = 打つコマンドなし**。
SW211/SW212 も同様に全 L3 インターフェース投入済み。

### 残る Gi0/2・Gi1/3 は SD-WAN（cEdge）向けの L2 トランク

IP を持たないので OSPF を乗せられない。接続先は cEdge21/cEdge22（SD-WAN ルータ）:

```
SW201-Gi0/2  <-> cEdge22-Eth0/0   (4518行)
SW201-Gi1/3  <-> cEdge21-Eth0/0   (4532行)
SW202-Gi0/2  <-> cEdge21-Eth0/1   (4525行)
SW202-Gi1/3  <-> cEdge22-Eth0/1   (4539行)
```

問題文が「すべての Layer 3 の**非 SD-WAN** ルータ間」とわざわざ断っているのは、この cEdge との
境界を指している。SD-WAN 向けの L3 到達性は SVI（Vlan3999/Vlan4000）が担っており、それも
初期コンフィグで OSPF 済み。

### MD5 認証も不要

要件は「**R11 と R12** は本社内の対向ルータとの隣接を MD5 で保護」に限定されている。
SW201 のネイバーは R21/R22/SW211/SW212/SW101/SW202 で、R11/R12 とは直接隣接していない。
（同じ理由で SW101 の Gi0/2（→SW201）にも MD5 は入れない）

### これは Task 1.5 全体で起きているパターン — 解答は「差分」しか載せない

| 機器 | 初期コンフィグの OSPF | 解答での実質的な作業 |
|---|---|---|
| R11 / R12 | **何もなし** | Lo0 + Gi0/1-3 を area 0 へ ＋ MD5 認証 |
| R21 | Lo0/Gi2/Gi3/Gi4 すべて済 | **`redistribute bgp 65002 metric-type 1 subnets` だけ**（interface 行は再入力で冗長） |
| R22 | `router ospf 1` の箱だけ（I/F 未設定） | Lo0 + Gi2-4 を area 0 へ |
| R23 / R24 | **何もなし** | router-id 明示 + Lo0 + Gi2-3 |
| SW101 / SW102 | Lo0・Gi0/0-2 済、**Vlan2000/2001 のみ未** | Vlan2000/2001 追加 ＋ Gi0/0-1 に MD5 |
| **SW201 / SW202** | **全 L3 I/F 済** | **なし** |
| **SW211 / SW212** | **全 L3 I/F 済** | **なし** |

SW101 の Gi0/0-1 も R21 の Gi2-4 も、解答の `ip ospf 1 area 0` は既に入っている行の再入力
（冪等なので無害）。**「解答に無い = 使わない」ではなく「解答に無い = 既に入っている」**が
このラボの一貫した読み方。

実機では以下 2 コマンドの差分で機械的に判定できる
（[[2026-08-03_q5_OSPF設定済みIFの確認コマンドと追加設定の見分け方]] 参照）:

```ios
show ip interface brief | exclude unassigned    ! L3 インターフェース一覧
show ip ospf interface brief                    ! OSPF 有効な一覧
```

SW201 ではこの差分が空になるので「作業なし」と確定できる。
