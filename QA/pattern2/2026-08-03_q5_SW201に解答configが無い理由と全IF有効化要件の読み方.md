# Pattern 2 Task 1.5 — SW201 に解答 config が無い理由と「全インターフェースで OSPF 有効化」要件の読み方

## 質問

CCIE_train_hub/Questions/pattern2/pattern2_q5.md
SW201において
interface range GigabitEthernet0/0-1　これにしかospfの設定をしていないけど　問題文では「OSPFはすべてのインターフェースで有効化しなければならない」と書いてある　なぜSW201ではこのインターフェースだけに設定したらいいとわかる？

## 回答

### 前提の訂正: `interface range GigabitEthernet0/0-1` は SW101/SW102 の config

original を SW201 で grep すると、SW201 が登場するのは **Pattern 3 の 2 箇所のみ**:

- `router ospf 1 / router-id 10.2.255.201`（Pattern 3 のみ）
- `interface GigabitEthernet1/2` に MD5 認証（Pattern 3 のみ）

**Pattern 2 Task 1.5 に SW201 の config は 1 行も存在しない。** `interface range GigabitEthernet0/0-1`
が出るのは SW101 / SW102（Gi0/0・Gi0/1 が R11/R12 直結のため MD5 認証を追加する必要があった）。

### 本質: 解答資料は「初期コンフィグからの差分」しか書いていない

このラボ全体を通じた最重要の読み方。**解答に機器名が無い ＝ そこで OSPF を使わない、ではない。**
「すでに設定済みで打つことが無い」だけ。

#### SW201 の初期コンフィグ（EI_v2.yaml）

| I/F | IP | 接続先 | 初期 `ip ospf 1 area 0` | Task 1.5 の作業 |
|---|---|---|---|---|
| Loopback0 | 10.2.255.201/32 | — | 設定済み | なし |
| Gi0/0 | 10.2.10.2/30 | R21 Gi4 | 設定済み | なし |
| Gi0/1 | 10.2.12.2/30 | R22 Gi3 | 設定済み | なし |
| Gi0/2 | （L2 trunk） | cEdge22 Eth0/0 | — | 対象外（SD-WAN 側 + L2） |
| Gi0/3 | 10.2.109.1/30 | SW202 Gi0/3 | 設定済み | なし |
| Gi1/0 | 10.2.23.1/30 | SW212 Gi0/1 | 設定済み | なし |
| Gi1/1 | 10.2.20.1/30 | SW211 Gi0/0 | 設定済み | なし |
| Gi1/2 | 10.2.241.1/30 | SW101 Gi0/2 | 設定済み | なし |
| Gi1/3 | （L2 trunk） | cEdge21 Eth0/0 | — | 対象外（SD-WAN 側 + L2） |
| Vlan3999 | 10.2.201.11/29 | — | 設定済み | なし |
| Vlan4000 | 10.2.201.3/29 | — | 設定済み | なし |

L3 インターフェース 9 本すべてが最初から `ip ospf 1 area 0`。**差分ゼロなので解答に SW201 の欄が無い。**
Gi0/2・Gi1/3 は `switchport mode trunk` の L2 ポートで OSPF を乗せられず、接続先が cEdge21/cEdge22 の
ため問題文の対象範囲「すべての Layer 3 の**非 SD-WAN** ルータ間」からも外れる。

問題文の除外リスト（R23-GE4 / R24-GE4 / R21-GE1 / R22-GE1 / R11-GE0/0 / R12-GE0/0）にも SW201 の
インターフェースは含まれない。つまり SW201 は「全 L3 IF で OSPF 有効」が正解で、初期状態で既に満たされている。

#### 比較: SW101 で差分が出た理由

| SW101 の I/F | 初期状態 | Task 1.5 の作業 |
|---|---|---|
| Lo0 / Gi0/2 | `ip ospf 1 area 0` 済み | なし |
| **Vlan2000 / Vlan2001** | IP はあるが OSPF 未設定 | `ip ospf 1 area 0` を追加 |
| **Gi0/0（→R11）/ Gi0/1（→R12）** | OSPF 済みだが認証なし | 対向 R11/R12 が MD5 必須 → **認証だけ追加** |
| Gi1/2, Gi1/3, Gi2/0, Gi2/1, Po1, Po3 | L2 trunk | 対象外 |

SW101 の `interface range Gi0/0-1` は「ここにだけ OSPF を有効化する」ではなく
**「すでに OSPF が有効なここに MD5 認証を追加する」**という意味。要件「すべてのインターフェースで
有効化」は Vlan2000/2001 の追加のほうで満たしている。

### 実試験でどう判断するか

答えを見ずに判断する手順は「まず既存設定を読む」:

```
show ip ospf interface brief                       ← どの I/F が既に OSPF に入っているか一覧
show ip ospf interface | include authentication    ← 認証の有無
show ip interface brief                            ← L3 / L2（unassigned）の切り分け
show run | section ^interface                      ← switchport かどうかの確認
```

`show ip ospf interface brief` の出力と問題文の除外リストを突き合わせ、足りない分だけ打つ。
SW201 でこれを打つと 9 本すべて出てくるので「打つことが無い」と判断できる。
