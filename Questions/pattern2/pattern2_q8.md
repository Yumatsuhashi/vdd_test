# Global SP #1：MPLS・BGP設定

以下の要件を満たすように、**Global SP #1でMPLSおよびBGPを設定しなさい。**

## 1. PEルータの構成

ルータ **R3、R4、R5、R6** を、PE（Provider Edge）ルータとして構成すること。

### VPNv4ルートの交換

- PEルータ同士でVPNv4ルートを交換できるようにすること。
- ルートリフレクタは使用しないこと。

### FABD2 VRFのルート交換

- Vander側で生成されたすべてのルートを、各PEルータの **FABD2 VRFルーティングテーブル** にインポートおよびエクスポートすること。
- 次の拠点に接続されているルートも対象に含めること。
  - Branch #3
  - Branch #4

### BGPピア数

- R3には、アクティブなBGPピアが5つ存在すること。
- R6には、アクティブなBGPピアが5つ存在すること。

### R3の最大プレフィックス制御

R3がData Centerルータから受信するプレフィックスについて、次の動作を実現すること。

- 受信プレフィックス数が **80,000を超えた場合**、警告メッセージを生成すること。
- 受信プレフィックス数が **100,000を超えた場合**、該当するBGPセッションをシャットダウンすること。
- シャットダウンされたBGPセッションは、**5分後に自動的に再確立**されること。

### 注意事項

- IaaSサイトは、このタスクの対象に含まれない。
- すべてのルータで、次のRoute Targetを使用すること。

```text
RT 10000:1
```

## 2. Pルータの構成

ルータ **R1およびR2** を、P（Provider）ルータとして構成すること。

- R1およびR2では、BGPを動作させてはならない。
- R1およびR2は、ラベルに基づいてパケットを転送すること。

## 3. BGPセッションの認証

Global SP #1内のすべてのBGPセッションを、次のパスワードを使用して保護すること。

```text
CCIE!nfr4
```
