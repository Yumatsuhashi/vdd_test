# 1.10 BGP 高速フェイルオーバー

Xander は、ネットワークに次の要件を実装しようとしています。

- ルータ **R5 と R61 間のリンク**、およびルータ **R6 と R62 間のリンク**に、強化された障害検出を設定してください。
  - リンクを **333ミリ秒ごと**にポーリングし、**3回連続でポーリングに失敗した場合**に障害状態とみなすこと。
  - 障害発生時は、リンクが復旧するまで **BGPピアをダウン状態**にすること。

- **偽造IPパケットを用いてCPU使用率を高める攻撃**から、**R5–R61間**および**R6–R62間**のBGPセッションを保護してください。
  - R5–R61間およびR6–R62間のルータは、**1ホップ先のルータとのみeBGPセッションを確立**すること。
  - R5–R61間のBGPピアリングで使用されるTCPセッションには、**MD5フラグを付与**すること。
