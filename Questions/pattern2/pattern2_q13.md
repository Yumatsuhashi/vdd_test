# 1.13 レイヤ2ポートセキュリティ

MACアドレスフラッディングからCAMテーブルを保護するため、次の要件を満たすようにスイッチ **SW700** を設定してください。

- **HOST71** を **VLAN 100** に、**HOST72** を **VLAN 414** に所属させること。

- ダウンストリーム側のホストに接続されているすべてのアクセスポートでは、SW700のCAMテーブルに学習できるMACアドレスを **1つだけ**に制限すること。

- ポートセキュリティの要件を満たすため、HOST71およびHOST72のMACアドレスを **スタティックに設定**すること。

- HOST71に接続されたポートで、別の未知のMACアドレスからパケットを受信した場合は、次の動作を行うこと。
  - パケットを破棄する。
  - syslogメッセージを送信する。
  - 違反カウンタを増加させる。

- HOST72に接続されたポートで、別の未知のMACアドレスからパケットを受信した場合は、そのポートを自動的に **err-disabled状態**にすること。

- HOST72に対して、ポートセキュリティの **絶対エージング時間を60秒**に設定すること。

- 違反によってerr-disabled状態になった場合、SW700のアクセスポートが **3分ごとに自動復旧**するように設定すること。
